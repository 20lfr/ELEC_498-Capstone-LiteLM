# Vitis Commands
To Run C Simulation (Example):
vitis-run --mode hls --csim --config ../vitis_simulations/Top_module_Non_Debug_Multiple_Token/hls_config.cfg --work_dir ../vitis_simulations/Top_module_Non_Debug_Multiple_Token

To Run Synthesis (Example):
v++ -c --mode hls --config ../vitis_simulations/Top_module_Non_Debug_Multiple_Token/hls_config.cfg --work_dir ../vitis_simulations/Top_module_Non_Debug_Multiple_Token

To Run Package (Example):
vitis-run --mode hls --package --config ../vitis_simulations/Top_module_Non_Debug_Multiple_Token/hls_config.cfg --work_dir ../vitis_simulations/Top_module_Non_Debug_Multiple_Token

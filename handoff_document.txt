## Handoff Document: DMA Tiling Implementation

### Objective
The goal of this task was to implement DMA-fetched tiling for the Q, K, V, and ATT_VALUE stages of the transformer head operations. This mirrors the existing efficient tiling mechanism used in the ATT_SCORES stage, aiming to reduce on-chip buffer pressure by fetching data in smaller, tiled chunks rather than single large transfers.

### Summary of Implemented Changes
The implementation is complete according to the plan. All necessary code modifications have been made across `shared_params.hpp`, `head_helpers.cpp`, and `mmu_luka.cpp`.

Here is a breakdown of the changes:

#### 1. `Model-architectures/phi3-mini-int4-HARDWARE/HLS-Verilog/shared_params.hpp`
- Added the `STRIDE_QKV_HEAD_TILE` constant to define the memory stride between tiles of the Q, K, and V weight matrices.

#### 2. `Model-architectures/phi3-mini-int4-HARDWARE/HLS-Verilog/Scheduler_FSM/src-hls/Head_Helpers/head_helpers.cpp`
- **Q, K, V, and ATT_VALUE State Machines:**
  - The `drive_head_state` function was modified to implement a per-tile DMA-and-compute cycle for the `Q`, `K`, `V`, and `ATT_VALUE` phases.
  - Instead of fetching all data at once, the logic now issues a DMA request for each tile, waits for it to complete, triggers the corresponding compute operation, and then proceeds to the next tile. This pattern was copied directly from the `ATT_SCORES` implementation.

#### 3. `Model-architectures/phi3-mini-int4-HARDWARE/HLS-Verilog/MMU/mmu_luka.cpp`
This file saw the most significant changes to support the new tiling mechanism:
- **`calc_dma_base_addr`**: Updated to use the `tile` index to calculate the correct starting address for each DMA transfer of `WQ`, `WK`, `WV`, and `CTX_V` data.
- **`build_dma_piece_plan`**: Modified to request smaller, tile-sized DMA transfers (`QKV_W_TILE_BYTES` and `ATT_VALUE_V_CACHE_TILE_BYTES`) instead of the full-sized transfers.
- **`calc_dma_piece_addr`**: Implemented special strided addressing logic for `DMASEL_CTX_V`. This correctly calculates the memory address for each piece of a `d_heads`-tiled V-cache transfer, where the data for a single tile is non-contiguous in DDR.
- **`DMA_ISSUE` State**: Added logic to limit the DMA burst size for `DMASEL_CTX_V` transfers. This ensures that a single DMA burst does not cross the boundary of a row in the V-cache, which is necessary for the strided access pattern.
- **`DMA_STORE` State**: Updated the region keying logic to use the `active_dma_tile` index for `WQ_W`, `WK_W`, `WV_W`, and `CTX_V` tags. This ensures that data for each tile is stored in a unique, identifiable buffer region.
- **`build_head_in_buf`**:
    - For `CMP_Q`, `CMP_K`, and `CMP_V`, the logic was updated to load weight data from the new tile-keyed regions using `load_region_to_buf`.
    - `load_ctx_v_tile_to_buf` was updated to correctly read from the new tile-keyed `CTX_V` region and perform the necessary data transpose for the compute controller.
